What I Built

ผมได้สร้างเว็บไซต์ Portfolio ง่าย ๆ ด้วย HTML กับ CSS ครับ โดยใช้ HTML สร้างโครงหน้าเว็บ เช่น หัวข้อ Portfolio รูปภาพ และลิงก์ Instagram ส่วน CSS ใช้จัดให้ตัวหนังสืออยู่กึ่งกลางหน้าให้ดูสวยขึ้น ตอนที่เปิดเว็บจากเครื่องตัวเองยังไม่มี server เกิดขึ้นครับมีแค่ client คือ browser เท่านั้น เพราะ browser แค่เปิดอ่านไฟล์จากเครื่องเราตรงๆผ่าน file ไม่ได้มีการส่ง request ไปหา server ที่ไหนเลยต้องรันผ่านโปรแกรมอย่าง Live Server หรือเอาไปอัปโหลดขึ้นเว็บจริงๆถึงจะมี server เกิดขึ้น

How I Built It

ผมได้พัฒนาชิ้นงานนี้เริ่มจากสร้างไฟล์ HTML ชื่อ index.html แล้วเขียนโครงหน้าเว็บเบื้องต้น มี head กับ body ใส่ title กับหัวข้อ Portfolio ด้วย h1 ก่อน หลังจากนั้นเพิ่มไฟล์ style.css แล้วเชื่อมกับ HTML ผ่านแท็ก link เพื่อจัดให้ตัวหนังสือ Portfolio อยู่กึ่งกลางหน้า เครื่องมือที่ใช้คือ VS Code สำหรับเขียนโค้ด และใช้ Live Preview ดูผลลัพธ์แบบเรียลไทม์ ส่วนแหล่งข้อมูลที่ช่วยเรียนรู้คือ การฝึกทำจากในห้องเรียน เเละ โจทย์ที่อาจารย์ได้ให้มา รวมถึงการค้นหาข้อมูลจากอินเทอร์เน็ตเพิ่มเติมด้วยครับ

Reflection

ปัญหาที่เจอคือรูปภาพไม่ขึ้นหลังจากใส่แท็ก img เข้าไปแล้วเเต่รูปไม่ขึ้นแสดง ตอนแรกไม่รู้ว่าต้องเช็คตรงไหนเลยลองไล่เช็คทีละจุด ทั้งชื่อไฟล์ นามสกุลไฟล์ ตำแหน่งไฟล์ว่าอยู่โฟลเดอร์เดียวกับ html หรือเปล่า จนสุดท้ายก็พบว่านามสกุลไฟล์ไม่ถูกต้องจึงเเก้ไขได้ จากการทำงาน A1 นี้ทำให้เข้าใจมากขึ้นว่า HTML กับ CSS ทำงานแยกกันคนละหน้าที่ HTML เป็นตัวสร้างโครงสร้างเนื้อหา ส่วน CSS เป็นตัวจัดรูปแบบให้สวยงาม
